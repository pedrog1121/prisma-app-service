# Prisma App Service

App móvil multiplataforma (**Android e iOS**) desarrollada con **Flutter**.

## Primeros pasos

Requisitos: Flutter SDK 3.24+ (Dart 3.5+), Android Studio y/o Xcode.

```bash
# Genera las carpetas nativas android/ e ios/ (solo la primera vez)
flutter create --platforms=android,ios --org com.prisma .

flutter pub get
flutter run
flutter test
```
